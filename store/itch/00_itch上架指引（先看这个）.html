One Hammer Deal · itch.io 上架指引

itch.io 是海外的独立游戏网站，不用审核，填完点发布就上线。页面全是英文，下面每一步写了对应的英文按钮名。英文游戏名用游戏里已有的 One Hammer Deal；海外玩家打开时，游戏会按浏览器语言自动显示英文（10 种语言都有）。

1注册账号

  1. 打开 itch.io，右上角 Register。
  2. 用户名会变成你的主页网址（例如 firesideginger.itch.io），建议用工作室的英文名，比如 firesideginger。
  3. 勾选 I'm interested in distributing content on itch.io（我要发布作品），这样才有发布入口。
  4. 去邮箱点验证链接。没验证邮箱的话，作品不能公开。

登录后右上角头像旁的箭头 → Upload new project（或 Dashboard → Create new project）。按顺序填：

3上传游戏

Uploads点 Upload files，选 01_上传包/one-hammer-deal-itch.zip（不要解压）。传完后在文件下面勾选 This file will be played in the browser。
Embed options选 Embed in page（在页面里直接玩）
Viewport dimensions960 × 640。这个尺寸下游戏会用电脑版的横向布局（左边铁匠铺，右边按钮和行情）。
Frame options勾选 Mobile friendly，Orientation 选 Portrait（手机竖屏）；勾选 Fullscreen button。
不要勾 Automatically start on page load（声音要玩家点一下才能出来）和 Enable scrollbars。

itch 要求 zip 里 index.html 放在最外层，和 TapTap（要套一层文件夹）正好相反，所以两个包不能混用。

You run a smithy that can forge anything: swords, cleavers, a salted fish, a toilet plunger, a power drill… Every strike can level your item up, or shatter it. The higher it goes, the more it's worth and the easier it breaks. Will you strike one more time? • A blade market that moves like a stock chart: every strike ticks the price, with daily candles and market news • A loan shark who comes for his money every 3 days, and wants more each time • Fever: fill the fire meter for 8 free strikes. 6保存、试玩、公开

  1. 点最下面 Save & view page，会打开游戏页面。
  2. 点 Run game 试玩：能开局、能锤、有声音；点右下角全屏按钮也试一下。用手机打开同一个网址再试一次。
  3. 没问题就回到编辑页（页面顶部 Edit game），把 Visibility 改成 Public，再 Save。
  4. 把游戏网址（形如 你的用户名.itch.io/one-hammer-deal）发给我，我把它加进 GitHub 主页和开发总结里。
